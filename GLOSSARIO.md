# Glossario canonico dell'Officina

Lessico chiuso. Nuovo termine? Si propone in DOMANDE_APERTE.md.

| Termine | Significato |
|---|---|
| Commessa | un progetto per un committente esterno, con vita propria in `70_progetti/<slug>/` |
| Committente | il cliente esterno pagante |
| Scoping | fase 0 di ogni commessa |
| Ipotesi di Valore | assunzione centrale non ancora verificata su cui si regge la commessa |
| Prototipo Minimo Verificabile | il più piccolo artefatto che mette alla prova l'Ipotesi di Valore |
| Segnale | dato osservato che conferma o smentisce un'Ipotesi di Valore |
| Punto di Decisione | momento previsto in cui si decide proseguire / tagliare / fermarsi |
| Data Flywheel | meccanismo per cui l'uso del prodotto genera dato che lo migliora |
| Debito Tecnico | scelta di implementazione veloce ma peggiore nel tempo, con costo di estinzione |
| Debito di Rischio | rischio noto e accettato temporaneamente, con scadenza |
| Consegna | artefatto o milestone che esce verso il committente |
| Parere di Rilascio | verdetto del Custode: FIRMATA / FIRMATA CON CONDIZIONI / NON FIRMATA |
| Sprint | unità di lavoro del Regista su tutte le commesse attive |
| Fase di Commessa | Scoping → Prototipo → Punto di Decisione → Sviluppo → Rilascio → Manutenzione |

## Formulazioni vietate

«lo implementiamo e vediamo» senza Ipotesi di Valore dichiarata · «per ora va
bene così» riferito a compliance o sicurezza · qualunque claim di mercato
senza etichetta di rigore.
